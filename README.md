One sentence, at most 200 characters, about the best meal I ever had.

The program writes a single sentence to `/output/entry.txt`: a midnight
soto ayam cart in Yogyakarta, broth so hot it fogged my glasses while the
vendor ladled it over rice and crisp fried shallots. No network, no
randomness — the same sentence, byte-identical, on every run.

Run it with Node 22:

```
node main.ts
```
